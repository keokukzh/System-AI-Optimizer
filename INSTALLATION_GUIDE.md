# 🚀 OptiAI Installation Guide

## 📦 **Was du jetzt hast:**

Du hast erfolgreich OptiAI heruntergeladen! Hier ist was in deinem Download-Ordner ist:

```
📁 OptiAI-v1.0.0/
├── 🖥️ OptiAI.exe                    # Hauptanwendung (319 MB)
├── 📄 index.html                    # Frontend-Interface
├── 📁 assets/                       # UI-Ressourcen
├── 🔧 install_optiai.bat           # Installations-Script
└── 📖 INSTALLATION_GUIDE.md        # Diese Anleitung
```

## 🛠️ **Installation (3 einfache Schritte):**

### **Schritt 1: Installation ausführen**
- **Doppelklick** auf `install_optiai.bat`
- Installation läuft automatisch (ca. 30 Sekunden)
- OptiAI startet automatisch nach der Installation

### **Schritt 2: OptiAI starten**
- **Desktop-Symbol** doppelklicken, ODER
- **Start-Menü** → OptiAI, ODER
- `C:\Users\[Benutzername]\OptiAI\OptiAI.exe` direkt ausführen

### **Schritt 3: Erste Nutzung**
- OptiAI öffnet sich automatisch
- Backend startet im Hintergrund
- Frontend lädt in deinem Browser
- **Fertig!** 🎉

## 🆘 **Hilfe & Support:**

### **Probleme beim Start?**
- Stelle sicher, dass Windows Defender OptiAI nicht blockiert
- Führe OptiAI als Administrator aus
- Prüfe, ob Port 5174 frei ist

### **Performance-Probleme?**
- OptiAI benötigt mindestens 4GB RAM
- Stelle sicher, dass genügend Festplattenspeicher vorhanden ist
- Schließe andere ressourcenintensive Programme

### **Features funktionieren nicht?**
- OptiAI benötigt Internetverbindung für KI-Features
- Stelle sicher, dass Windows-Updates installiert sind
- Prüfe die Firewall-Einstellungen
